## Current State Details

- Storage: Cloudflare D1 (`alixsbrain`) is the active shared source of truth. The local SQLite prototype contains no meaningful production data and is no longer the active system.
- Capture interface: Telegram bot connected to `POST /telegram/webhook`; accepted messages are stored in D1 and receive a `Saved.` confirmation.
- Review interface: Responsive authenticated dashboard deployed at `https://alixsbrain-capture.alix-98e.workers.dev`; works without a local computer being online.
- Dashboard workflow: Shows every capture as an item, supports manual categorization and metadata editing, filters by status/category/domain/requester, and provides Done/Reopen, Waiting, Archive/Restore, and confirmed permanent deletion.
- Item model: One primary category separated from optional domain, requested-by, project, multiple flags, and due date/time. Status is Inbox, Open, Waiting, Done, or Archived.
- Processing: Intentionally minimal. Telegram and dashboard messages are immediately stored as uncategorized Inbox items. Categorization remains manual, and raw capture text is preserved independently from item metadata.
- Security: Telegram webhook secret plus Telegram user allowlist for ingestion; separate HTTP Basic credentials stored as Worker secrets for all dashboard assets and APIs.
- CI/CD: None configured; deployments and migrations are currently run manually with Wrangler.
- Observability: Cloudflare Worker invocation and structured event logs are enabled at full sampling for the low-volume field test. Custom events exclude capture text, Telegram identity, credentials, and tokens.
- Recovery: D1 Time Travel is available, and `npm run db:export` creates a private Git-ignored SQL export. Recovery procedures are documented in `docs/OPERATIONS.md.txt`.
- Validation: The seven-day procedure, exception log, and success criteria are documented in `docs/FIELD_TEST.md.txt`.
- Current implementation: Deployed V1 test system using Telegram → Cloudflare Worker → Cloudflare D1, with the Worker also serving the protected review dashboard and API.
