# External Brain

## Purpose

Build a trusted external brain that reduces cognitive load by capturing, organizing, prioritizing, and surfacing information so the user does not have to act as the database for their life and business.

The goal is not automation for its own sake.

The goal is not to build agents.

The goal is to reduce the amount of information the user must personally remember.

## Non-Negotiable Constraints

* Reduce cognitive load first.
* Build the smallest useful thing.
* Prefer manual workflows before automation.
* Minimize cost when reasonable.
* Avoid unnecessary infrastructure.
* Avoid complexity that does not create value.
* Recommendations before automation.
* Technology decisions should follow problems, not trends.

---

## Current Success Metric

The project is succeeding if it reliably reduces the number of things the user must personally remember.
